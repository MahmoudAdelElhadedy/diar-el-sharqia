## 🌟 نظرة عامة على المشروع
تطبيق ويب متطور مبني بأحدث إصدارات **Angular 18** بنظام المكونات المستقلة (**Standalone Components**)، متجاوب بالكامل مع كافة الشاشات وأجهزة الجوال، وموجه بالكامل باللغة العربية (`dir="rtl"`). 

تم تصميم المنصة لتخدم الأنشطة الاستراتيجية الثلاثة لشركة **ديار الشرقية**:
- **التشطيبات الفندقية والأبراج السكنية:** إبداع معماري وديكورات فاخرة للوحدات والقصور والأبراج.
- **المقاولات العامة والبنية التحتية:** تنفيذ المشروعات الإنشائية الكبرى والمحاور والكباري وفق الكود الهندسي الدولي.
- **استصلاح الأراضي والري الحديث:** استصلاح آلاف الأفدنة بنظم الري المحوري (Pivot) والطاقة النظيفة لتعزيز الأمن الغذائي القومي.

## 🏛️ أبرز المميزات والصفحات المنفذة

### 1. الشريط العلوي الذكي (Navbar) & الفوتر الاحترافي (Footer)
* **Navbar ذكي وديناميكي:** يبدأ بشفافية أنيقة مدمجة مع السلايدر، ويتحول إلى خلفية داكنة فخمة مع تأثير زجاجي معالج (`backdrop-filter: blur(14px)`) وحدود ذهبية دقيقة عند التمرير، مع مؤشر للرابط النشط، وزر سريع لحجز استشارة، وقائمة جانبية متجاوبة للجوال.
* **Footer فاخر من 4 أعمدة:** يضم ملخص رؤية الشركة، روابط الوصول السريع لكافة المجالات، بيانات الاتصال، وشريط شبكات التواصل الموحد (Facebook, Instagram, TikTok, Snapchat, YouTube, Email, WhatsApp).

### 2. الصفحة الرئيسية (Home Page)
* **Hero Slider ملء الشاشة (100vh):** سلايدر تفاعلي ثلاثي مع تنقل تلقائي (كل 6 ثوانٍ) ويدوي، وتظليل أسود شفاف متدرج (`rgba(0,0,0,0.55)`) يبرز جمالية الصور الحقيقية بدقة 1920px مع الحفاظ على وضوح النصوص الذهبية والبيضاء.
* **قسم عن شركتنا:** صياغة مؤسسية تبرز ريادة الشركة في الجمع بين البناء الحديث واستصلاح الأراضي مع بطاقات تميز معمارية وشارات عائمة.
* **كروت قطاعات التميز الثلاثة:** تصميم تفاعلي ثلاثي الأبعاد مع روابط تصفية سريعة.
* **مقتطفات من أحدث المشروعات:** بطاقات معاينة سريعة لأبرز المشاريع القائمة.
* **بانر الدعوة للتواصل المباشر (CTA Banner):** يتيح الاتصال الهاتفي السريع بنقرة واحدة.

### 3. صفحة عن الشركة (About Page)
* تفاصيل موسعة عن تاريخ الشركة ومسيرتها انطلاقاً من محافظة الشرقية.
* الرؤية والرسالة المؤسسية والقيم الجوهرية (الجودة المطلقة، النزاهة، الالتزام بالمواعيد، والاستدامة).
* أرقام وإنجازات الشركة (+15 عاماً، +250 مشروعاً، +50,000 فدان مستصلح، +1,200 شريك).
* جدول زمني تفاعلي (Milestones Timeline) يستعرض محطات نمو الشركة من 2009 حتى اليوم.

### 4. صفحة مشاريعنا وأعمالنا (Projects Page)
* **أزرار تصفية فورية (Tabs Filter):** تتيح للمستخدم التبديل بين (جميع المشاريع، تشطيبات فندقية وأبراج سكنية، مقاولات عامة وبنية تحتية، استصلاح أراضي زراعية).
* **معرض بطاقات المشروعات:** واجهة أنيقة تركز على الصورة والعنوان.
* **نافذة تفاعلية منبثقة (Asymmetrical Mosaic Gallery Modal):** عند النقر على أي مشروع، تفتح نافذة تعرض ألبوم صور بتنسيق الفسيفساء غير المتماثل (Mosaic)، مع شريط المواصفات الفنية.
* **عارض الصور التفاعلي (Fullscreen Lightbox Viewer):** إمكانية تكبير أي صورة في كامل الشاشة والتنقل بين الصور عبر الأسهم ولوحة المفاتيح.

### 5. صفحة تواصل معنا (Contact Page)
* **نموذج تواصل تفاعلي ذكي (Reactive Forms):** يقتصر على الحقول الأساسية لسرعة التواصل (الاسم، رقم الهاتف، والرسالة) مع التحقق الفوري وعرض رسائل الخطأ بالعربية، ورسالة تأكيد استلام فاخرة.
* بطاقات بيانات المقرات الرئيسية (التجمع الخامس بالقاهرة والزقازيق بالشرقية).
* أرقام الهاتف والخط الساخن، والبريد الإلكتروني الرسمي، ومواعيد العمل.
* زر محادثة فورية عبر **واتساب** بنقرة واحدة.
* خريطة موقع جغرافية توضح مقرات ومراكز الشركة.

## ⚡ هندسة الأداء وتحسين محركات البحث (SEO & Core Web Vitals)

1. **تقسيم الكود والتحميل الكسول (Route-Level Code Splitting):**
   * تحويل كافة المسارات إلى التحميل الكسول عبر `loadComponent`.
   * انخفاض حجم حزمة الدخول الرئيسية `main.js` من **476.80 kB** إلى **30.42 kB** فقط (توفير بنسبة 93.6%).
   * تفعيل التحميل المسبق الصامت `PreloadAllModules` للتنقل اللحظي بين الصفحات دون أي تأخير (**INP < 50ms**).
2. **ضغط وتخفيف أوزان الصور بنسبة 87.5%:**
   * تم خفض وزن الصور من **~20 MB** إلى **~2.5 MB** دون أدنى فقدان في الجودة البصرية.
   * تضمين خاصية التحميل الكسول `loading="lazy"` والفك غير المتزامن `decoding="async"`.
   * تحميل مسبق لصورة الـ LCP الأساسية عبر `<link rel="preload" as="image" fetchpriority="high">`.
3. **تثبيت الأبعاد والقضاء التام على إزاحة الصفحة (CLS = 0):**
   * تزويد كل عنصر `<img>` في الموقع بأبعاد `width` و `height` صريحة لمنع قفزات المحتوى أثناء التحميل.
4. **البيانات المنظمة المعتمدة (Schema.org JSON-LD):**
   * حقن مخططات `Organization`, `GeneralContractor`, `RealEstateAgent`, `WebSite`, `BreadcrumbList`, و `ItemList`.
5. **خدمة SEO ديناميكية متكاملة ([seo.service.ts](src/app/services/seo.service.ts)):**
   * تحديث تلقائي للعنوان (50-60 حرفاً) ووصف الميتا (150-160 حرفاً) والروابط الكنسية `canonical` وبطاقات Open Graph و Twitter Cards عند كل تنقل.
6. **ملفات الزحف العالمية:**
   * ملف `robots.txt` وخريطة موقع `sitemap.xml` تضم مسارات وروابط صور المشاريع لمحرك صور Google.
7. **جاهزية التخزين المؤقت والضغط:**
   * ملفات `vercel.json`, `nginx.conf`, و `.htaccess` مجهزة بترويسات تخزين مؤقت لعام كامل للأصول الثابتة.

## 💻 التقنيات المستخدمة (Tech Stack)

* **الإطار الأساسي:** [Angular 18.2](https://angular.dev/) (Standalone Components Architecture)
* **اللغة البرمجية:** [TypeScript 5.5](https://www.typescriptlang.org/)
* **التصميم والتنسيق:** SCSS (Modern Responsive Design System)
* **مكتبة الأيقونات:** [FontAwesome 6 Free](https://fontawesome.com/) (مضمنة محلياً بالكامل ومطابقة للهوية)
* **الخطوط:** Cairo من Google Fonts مع `font-display: swap`
* **المعالجة غير المتزامنة:** RxJS 7.8
* **النشر الآلي:** GitHub Actions & GitHub Pages

## 🚀 طريقة التثبيت والتشغيل محلياً

### المتطلبات المسبقة:
* تثبيت **Node.js** (الإصدار 18 أو 20 أو أحدث).
* تثبيت **Angular CLI**:
  ```bash
  npm install -g @angular/cli
  ```

### خطوات التشغيل:
1. استنسخ المستودع:
   ```bash
   git clone https://github.com/MahmoudAdelElhadedy/diar-el-sharqia.git
   cd diar-el-sharqia
   ```
2. ثبّت الحزم والمكتبات:
   ```bash
   npm install
   ```
3. شغّل خادم التطوير المحلي:
   ```bash
   npm start
   ```
4. افتح المتصفح على الرابط:
   ```
   http://localhost:4200/
   ```

## 📤 طريقة النشر على GitHub Pages

المشروع مزود مسبقاً بملف سير عمل تلقائي عبر **GitHub Actions** في المسار [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) بالإضافة إلى ملف [`public/404.html`](public/404.html) لمعالجة التوجيه في تطبيقات الصفحة الواحدة (SPA Redirect).

### خطوات النشر في دقيقة واحدة:
1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub باسم: `diar-el-sharqia`.
2. اربط المجلد المحلي بالمستودع وارفعه:
   ```bash
   git remote add origin https://github.com/MahmoudAdelElhadedy/diar-el-sharqia.git
   git branch -M main
   git push -u origin main
   ```
3. في صفحة المستودع على GitHub:
   * اذهب إلى **Settings** > **Pages**.
   * تحت خيار **Build and deployment** > **Source**: اختر **GitHub Actions**.
4. سيعمل ملف الـ Action تلقائياً، وخلال دقيقة واحدة سيكون الموقع متاحاً على الرابط التالي لتشاركه مع العميل:
   👉 **`https://MahmoudAdelElhadedy.github.io/diar-el-sharqia/`**
